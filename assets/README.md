# Dashboard artwork and gallery

The bundled logo.webp and banner.webp are compact derivatives of the original Ingenium SMP lava crest and IngeniumBot banner. Add higher-resolution logo.png and banner.png here to override them. The site automatically includes PNG, JPG, JPEG and WebP gameplay screenshots committed to assets/gallery/. Use descriptive filenames and only publish screenshots approved for public viewing. Do not include player secrets, server console output or personal details.

Optional Streamlit secret: staff_owner = "Public staff display name". Existing server_address and discord_invite secrets still work; the retired wap-sane endpoint is migrated to wap-mojo.tun.ply.gg:9350 in the dashboard only. Update the secrets separately for clarity. The dashboard never changes the Minecraft host configuration.
