# Ingenium SMP
Minecraft Java 26.3 | Windows-hosted | IngeniumBot | Streamlit

## First-time setup (keep Playit OFF until authentication is tested)
1. Install 64-bit Java 25 (https://adoptium.net/temurin/releases/?version=25), Python 3.12+, and Git. Clone this private repository.
2. You can run SETUP_WINDOWS.bat for Python dependencies, default settings and import if world.zip is beside it. Alternatively, in PowerShell run `py -m venv .venv` and `.\.venv\Scripts\python.exe -m pip install -r requirements-host.txt`.
3. Place the original Aternos world ZIP outside the repo or next to it and run `.\.venv\Scripts\python.exe setup_host.py import-world world.zip`. Never overwrite the original. The archive contains six datapacks and four existing player saves. Offline UUIDs are preserved. Do not change authentication mode or player-name spelling.
4. Download the Minecraft 26.3 Fabric server launcher from https://fabricmc.net/use/server/ and save as `server/server.jar`. Install EasyAuth for **Fabric 26.3** and its required dependencies from https://modrinth.com/mod/easyauth/versions into `server/mods/`. Read the mod documentation; disable premium auto-login/UUID conversion if needed to preserve offline UUIDs. Confirm configured behavior in a local test. No client gameplay mods are intended.
5. Run `.\.venv\Scripts\python.exe setup_host.py configure` to create safe defaults and a local config.json. Edit config.json: set whitelist to the exact existing Minecraft usernames, configure Discord IDs and public address when available. Leave public_access_verified false initially. Read https://aka.ms/MinecraftEULA then explicitly change server/eula.txt to eula=true.
6. Create a Discord server named Ingenium SMP at https://discord.com/app. Create an application named IngeniumBot at https://discord.com/developers/applications, create its bot, enable Message Content intent, then install it in your server with bot and applications.commands scopes. Grant Manage Channels only if you want /setup_channels; grant View Channels, Send Messages, Read Message History, Embed Links. Do not grant Administrator. Enable Discord developer mode, copy server and your user IDs into config.json. Put the bot token in .env (DISCORD_TOKEN=...), not in GitHub or chat.
7. Run START_WINDOWS.bat. Use /setup_channels as the Discord server owner, or create channels yourself and enter their IDs in config.json. Restart the host after editing config. /start starts Minecraft; when autostart is true the host starts it on launch. /stop stops Minecraft but keeps the bot running. Ctrl+C stops both. Test locally on localhost:25565. Check datapack list, inventories and dimensions. Whitelist is generated from explicit config usernames; no player is made operator.
8. With Playit still OFF, register members securely. The host binds to loopback, so use local clients or the mod's documented administrator pre-registration/registration-code mechanism, if supported in the installed version. For interactive local console administration, first stop Minecraft and exit the Python host, then run java -Xmx6G -jar server.jar nogui from server/ with Playit off. Never run two Java servers on the same world. Stop with the stop command before returning to START_WINDOWS.bat. Do not expose unregistered names to an unrestricted tunnel. Disable shared-IP auto-login/session bypass for tunneled players and verify the actual authentication behavior. Do not expose unregistered names publicly; an attacker could register first. Verify login is mandatory and a second client cannot impersonate a registered player. Test old offline UUIDs and inventories. Set public_access_verified=true only when satisfied, and restart. This flag is an acknowledgement, not a security audit. Never expose RCON or console. Install Playit from https://playit.gg/download and create a Minecraft Java tunnel to 127.0.0.1:25565. Keep the agent running. Update public_address in config.json. Do not enable router port forwarding.
9. Deploy dashboard at https://share.streamlit.io using this repo, main, streamlit_app.py. Grant private repository access. In Advanced settings/secrets enter:
   ```toml
   server_address = "YOUR-PLAYIT-ADDRESS:PORT"
   discord_invite = "https://discord.gg/YOUR-INVITE"
   ```
   Share the app with your SMP members using Streamlit's sharing controls. Dashboard polls Minecraft's public status only; it does not expose the admin API or assume sample names are complete. Remote controls are through authorized Discord accounts.
10. Windows Settings > System > Power & battery > Screen and sleep: set plugged-in sleep to Never; screen timeout may be short. Keep the laptop ventilated and connected. Win+L is safe. For reboot recovery, use Task Scheduler at logon with the project directory as Start in and START_WINDOWS.bat as the program; the Playit agent also needs to start. Sleep/hibernation/ shutdown takes both Minecraft and the bot offline.

## Data safety
World, backups, logs, local configuration, authentication files and secrets are excluded from Git. Never commit world.zip or share the bot token. /backup works only when Minecraft is stopped; keep an independent backup on another drive. Keep the Aternos copy until migration tests pass. No Oracle deployment yet. A public tunnel is not an authentication layer.

## Features and limits
Discord /status /ip /players /start /stop /restart /backup /setup_channels; staff checks use configured Discord user IDs. Chat relay uses JSON tellraw, suppresses mentions and never forwards login/register commands. Minecraft console output formats need live 26.3 testing. Public dashboard supports status, version, latency, player count, datapack catalogue and connection instructions. No simulated stats. Offline-mode username identity requires independent authentication; whitelist alone is insufficient. Bot and dashboard cannot wake a sleeping laptop. No arbitrary console command endpoint. Backups and crash recovery are local.
